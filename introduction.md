 8 Core Pillers


1. Prompt Engineering
	How we prompt AI models today is very different from when ChatGPT first came out in 2022. As these tools have become more capable, the people who know how to use them well are getting significantly more done. Prompt Engineering is the critical art and science of formulating inputs to guide Large Language Models (LLMs) effectively. Whatever your current skill level, the course is designed to help you get a lot more out of AI in your daily work and life. You will learn how to design task-specific system prompts (e.g., instructing an LLM to act as a Senior Programmer) and how to write structured input instructions that force the model to consistently output clean data structures (like custom JSONs or precise tool-execution parameters).

2. Harness Engineering
	While a foundation model acts as an agent's core reasoning engine, it is completely helpless without a structural environment to live in. True enterprise readiness requires shifting focus away from tweaking prompts and moving toward engineering the resilient software operating system surrounding the model. Harness Engineering is the critical practice of constructing the secure, stateful runtime environment—the operational harness—that manages what an LLM cannot, including state, sandboxing, and runtime recovery. This course is designed to introduce you to the modern architectural standard where an autonomous system is programmatically defined as Agent = Model + Harness. You will learn to construct and navigate the authoritative ETCLOVG taxonomy layers: deploying secure execution sandboxes (microVMs via E2B), setting up localized file-level representations of runtime states, configuring tool discovery layers, orchestrating complex think-act-observe control loops, and designing programmatic circuit breakers to actively halt runaway execution loops.

3. Context Engineering
    Providing the Relevant Knowledge
    
    Static knowledge bases limit what an AI can do, and copy-pasting documents into a chat window manually quickly becomes a bottleneck. In the production landscape, managing the flow of data dynamically is what separates a generic chatbot from an elite enterprise system. Context Engineering is the strategic management, chunking, and retrieval of external information fed directly into an LLM's active context window. Whether you are dealing with massive code repositories or sprawling company wikis, this course is designed to help you supply models with high-density, highly relevant data without blowing past token limits. You will learn fundamental data chunking, indexing, and advanced retrieval strategies (semantic, keyword, and BM25 hybrid search). Crucially, you will master runtime summarization techniques, how to filter file system listings, and how to clip tool outputs or error stacks to keep your system fast and accurate.

4. Memory Engineering
    Building Stateful Agents
    Most AI agents today are "stateless"—they function brilliantly within a single conversation session but completely forget who you are and what they did once that session ends. Moving past this limitation requires shifting from simple prompting to building persistent data architecture. Memory Engineering is the process of designing structured, long-term memory systems external to the model so agents can store, update, and accumulate knowledge continuously across days or weeks. This course is designed to help you transition your AI from a short-term conversationalist into a deeply personalized assistant that retains context and learns over time. You will learn to build a centralized Memory Manager using an AI Database and LangChain. You will build pipelines that autonomously extract structured facts from raw conversations, consolidate short-term episodic logs into long-term semantic memory, and handle contradictions via self-updating write-back loops.

5. Agent Engineering
    The Core Autonomy Architecture
    Standard generative AI operates linearly—you give a prompt, it writes an essay. The true power of modern AI unlocked when we stepped away from single-turn inputs and moved toward autonomous, goal-driven loops. Agent Engineering is the architecture of designing iterative, multi-step systems where an LLM controls an execution loop, allowing it to plan, reflect on errors, utilize tools, and collaborate. This course is designed to take you to the cutting edge of AI development, moving away from static text generation and into the realm of fully autonomous problem-solving.
    Under Andrew Ng's guidance, you will learn to build core agentic design patterns from scratch, including Reflection (agents evaluating and correcting their own output or logs), Planning, and Multi-Agent Collaboration (prompting multiple simulated personas to iterate on a task together).

6. Agent Integration
    Connecting to Tools and APIs
    An AI model trapped in a silo can only tell you things; an AI model connected to your tools can actually do things for you. The next evolution of utility comes from seamlessly plugging AI directly into the software ecosystem we use every day. Agent Integrations is the technical practice of connecting agents natively to external technical ecosystems—enabling models to interact directly with databases, custom APIs, and complete programming libraries. This course is designed to bridge the gap between abstract AI reasoning and hands-on software execution, giving your agents real-world leverage. You will learn the foundations of tools, including what they are, how to create them, and tool syntax. You will master advanced execution patterns, including the Modal Context Protocol (MCP), and learn the practical workflows required to turn standard code functions into tools. Finally, you will apply these integrations to build production-ready practical workflows, such as an autonomous Email Assistant Workflow.

7. Agent Safety & Security (Gaurdrails)
    This pillar is dedicated to ensuring that the autonomous agent remains safe, reliable, and secure. This moves beyond basic alignment to the enforcement of technical Guardrails. You will learn to implement real-time input and output filtering. This includes hallucination detection (using NLI models, as referenced in image 0), preventions against jailbreaking and prompt injection, and sensitive data protection (redacting PII).

8. Agent Analytics & Evaluations
    Measuring Production Performance
    When building simple applications, you can eyeball the results to see if they look good. But as teams adopt rigorous, lean software principles for autonomous networks, having an objective, component-level framework to scientifically measure precision and trace system breakdowns is mandatory. Agent Analytics & Evals is the disciplined process of telemetry tracking, deep observability tracing, and metric-driven unit testing to systematically isolate where an agent failed in its chain of thought. This course is designed to substitute developers' guesswork with concrete, industry-standard evaluation pipelines to benchmark context relevance, groundedness, and token metrics. You will learn how to run evaluations (evals), analyze errors, prioritize next steps, and perform component-level evaluations to address latency, cost, and overall development performance. You will learn how to add a component-level eval directly to a research workflow. You will construct production-ready evaluation workflows using industry-leading toolkits: setting up DeepEval for Pytest-style automated unit testing via G-Eval metrics, utilizing Langfuse to track telemetry paths and multi-agent loops, deploying TruLens to pinpoint exactly where a chain of thought fractured, implementing Ragas to evaluate RAG pipelines without requiring human ground-truth data, and utilizing Arize Phoenix to replay deep execution traces and capture complete runtime provenance. Additionally, you will explore the broader ecosystem of evaluating and debugging generative AI using platforms like Weights & Biases.
